Cost model

Local logic is $0. Modal A100-40GB is $2.10/h. The Baseten brain bills per call. Only GPU trials and quality probes spend.

Evidence

14 typed event types go to events.jsonl (plus agent calls from agent-events.jsonl), then report.html. Any run re-renders offline.

Status

M0 and M1 are green. M2 is GPU-evaluated (0 wrong verdicts, $4.63), M3 brain live-probed, M4 tune GPU-evaluated (honest negative: baseline kept). See the Status section of the architecture page.

Quickstart

uv sync --group dev
printf 'PERFPILOT_LLM_API_KEY=%s\n' 'your-key' > .env   # optional: no key means deterministic fallbacks
uv run modal secret create huggingface HF_TOKEN=<token>
uv run modal deploy perfpilot/worker/modal_app.py
uv run perfpilot bisect --good <sha> --bad <sha>
uv run perfpilot report runs/<run-id>

GPU trials need Modal quota and your go-ahead. The expected cost is stated before every GPU run, and M1 stays under the ~$8 Sat-noon gate.

Run reports

Each run directory holds config.yaml, events.jsonl, report.html, results/ and logs/, plus fix.patch when one is drafted. Re-render any recorded run with perfpilot report runs/<id>. No GPU needed. watch writes the same page with a 5s auto-reload. Brain calls land in agent-events.jsonl beside it.
