# PerfPilot

Agent that keeps a vLLM deployment of a Meta open model fast.
**PerfBisect** finds the first slow commit; **TuneSmith** recovers speed via
serve flags. Every claim is benchmark-verified with intervals — never vibes.

Indie track, Push the Frontier. Plan and spec: [PLAN.md](PLAN.md), [SPEC.md](SPEC.md).
Interactive diagrams: [docs/](docs/index.html).

## How it works

Two planes. A free local control plane **decides and proves**; a metered Modal
A100 plane **measures**. The Baseten brain (`muse-spark-open`) only advises —
which commit to probe, whether more samples are needed, which flags to try —
and every proposal is schema-validated with a deterministic fallback when no
key is set.

```
bisect --good G --bad B → freeze wheeled range → pick SHA → run_trial (A100)
  → classify (Welch interval) → narrow → verdict: culprit + interval + GPU $
tune --commit C → propose flags → measure → quality gate (50Q bank)
  → best flags + serve_command + fix.patch
```

Two findings, both evidence-backed:
1. The strong overlay bites hard (~60% when measured cleanly) but a single
   outlier run can poison a 3-sample baseline — fixed in `run_bisect` via
   `baseline_max_spread` (default 0.30): endpoints re-measure once and keep
   the tighter set, logged in `pick_log`. Proven by
   `test_contaminated_baseline_remeasured_finds_culprit` replaying the exact
   `[3569, 3594, 1703]` evidence (and failing with the check disabled).
2. The mild overlay fails PLAN.md's own ≥10% keep rule on this workload
   (measured -0.8%). It should be dropped or replaced as an eval overlay —
   trial 1's `no_regression` is the *right* answer to the wrong premise.

## Known limitation

A culprit at the very first commit of the range is undetectable by
construction: every commit measures slow, so the range contains no clean
baseline and no transition. The driver honestly reports `no_regression`
instead of fabricating a culprit (locked in by
`test_eval_protocol_first_commit_reports_no_regression`). Only a pre-range
baseline could distinguish this case. The eval protocol therefore plants at
[1, 15] — index 1 is the lowest detectable position.

## Setup

Requires Python 3.12 and [uv](https://docs.astral.sh/uv/).
Key from env or local `.env` (gitignored, never logged); without a key the
drivers run deterministic fallbacks.

```sh
uv sync --group dev
printf 'BASETEN_API_KEY=%s\n' 'your-key' > .env
uv run perfpilot bisect --good <sha> --bad <sha>
uv run perfpilot tune --commit <sha>
uv run perfpilot report runs/<run-id>   # watch: live refresh
uv run perfpilot eval --trials 2        # GPU; needs quota + approval
make test   # pytest
make lint   # ruff check + format
```

Each run writes `runs/<id>/`: `config.yaml`, `events.jsonl`, `report.html`,
`results/`, `logs/` (+ `fix.patch` for tunes). Any report re-renders offline:
`perfpilot report runs/<id>`.
